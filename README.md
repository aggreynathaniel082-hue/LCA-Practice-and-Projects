# LCA-Practice-and-Projects
Life Cycle Assessment practice and project work using openLCA, demonstrating environmental impact modeling, data interpretation, and sustainability analysis skills.

## About

I'm exploring Life Cycle Assessment (LCA); a method for evaluating the environmental 
impacts of a product, process, or service across its entire life cycle, from raw 
material extraction through production, use, and disposal. Using **openLCA**, an 
open-source LCA software, I model real and practice scenarios to analyze environmental 
impacts such as carbon footprint, resource use, and emissions


## Repository Contents

Each project folder below includes:
- The goal and scope of the assessment
- Key assumptions and data sources
- Results (impact assessment outputs, charts, exported data)
- What the project demonstrates in terms of LCA methodology and analytical skills
